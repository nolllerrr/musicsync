# MusicSync 0.1.9

MusicSync синхронизирует команды и позиции официальной Яндекс Музыки на двух Windows-компьютерах. Звук воспроизводится локально на каждой машине. Сервер хранит одну ревизию состояния на комнату и передаёт её ведущему и слушателю через WebSocket.

## Запуск в Windows

Для режима «Вместе» запустите `MusicSync-Together-0.1.9-Windows-x64.exe`. В окне можно установить или удалить патч и сохранить адрес сервера. После установки комнаты открываются в разделе «Вместе» самой Яндекс Музыки. [Поддерживаемая версия и сборка](docs/TOGETHER.md)

## Отдельный клиент MusicSync

Распакуйте архив целиком. В папке будут два файла запуска, настройки и инструкция.

- `MusicSync.Client.exe` открывает MusicSync в обычном режиме.
- `Start-Sonata.cmd` запускает режим Sonata для переключения треков в свёрнутом окне Яндекс Музыки. Используйте его на обоих ПК. [Запуск в режиме Sonata](docs/TESTING.md#запуск-проверки-sonata)

В открывшемся окне ведущий создаёт комнату, а слушатель входит по коду. Во время прослушивания ведущий выбирает песни, ставит на паузу и перематывает в Яндекс Музыке. Участники могут поменяться ролями в той же комнате после подтверждения запроса. Если закрыть окно MusicSync, приложение останется в трее Windows.

## Сборка из исходников

На Windows с .NET 10 SDK из корня проекта выполните:

```powershell
dotnet build .\MusicSync.slnx -c Release
dotnet test .\MusicSync.slnx -c Release --no-build
.\scripts\Publish-Windows.ps1
```

Последняя команда публикует автономные Windows x64 клиент и сервер и создаёт клиентский ZIP с номером версии в `dist`. Зависимости клиента встроены в EXE. Ключ `-ClientOnly` публикует клиент в отдельной папке с номером версии.

## Локальный запуск

```powershell
dotnet run --project .\src\MusicSync.Server -c Release
```

Во втором PowerShell:

```powershell
dotnet run --project .\src\MusicSync.Client -c Release
```

Адрес по умолчанию — `ws://127.0.0.1:5050/ws`. Для второго компьютера настройте LAN-режим по инструкции.
