# MusicSync 0.1.10

MusicSync добавляет раздел «Вместе» в Яндекс Музыку для Windows. Ведущий создаёт комнату, а до девяти слушателей входят по коду. Ведущий может передать управление выбранному слушателю после его подтверждения. Звук воспроизводится локально на каждом компьютере. Сервер передаёт состояние воспроизведения между участниками через WebSocket.

## Запуск в Windows

Запустите `MusicSync-Together-0.1.10-Windows-x64.exe`, укажите адрес сервера и нажмите «Установить патч». После установки откройте «Вместе» в боковом меню Яндекс Музыки. [Установка и проверка на двух ПК](docs/TOGETHER.md)

## Сборка из исходников

Выполните команды из корня проекта на Windows с .NET 10 SDK.

```powershell
dotnet build .\MusicSync.slnx -c Release
dotnet test .\MusicSync.slnx -c Release --no-build
node --test tests/MusicSync.Tests/*.test.cjs
.\scripts\Publish-Together.ps1
```

Установщик для Windows x64 появится в `dist`. Групповые комнаты используют протокол v2: сервер и установленные клиенты нужно обновить совместно.
