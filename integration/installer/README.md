# MusicSync «Вместе» для Windows x64

Распакуйте ZIP целиком. Закройте Яндекс Музыку, запустите `Install.cmd`, затем снова откройте приложение. В боковом меню появится «Вместе». Чтобы снять патч, закройте Яндекс Музыку и запустите `Uninstall.cmd` из той же папки.

Поддерживается проверенная сборка Яндекс Музыки 5.126.1. Установщик сверяет SHA-256 оригинальных файлов и хранит их копии в `.musicsync-together` внутри каталога приложения. При удалении он сверяет SHA-256 файлов патча и восстанавливает оригиналы. Повторный запуск того же установщика проверяет установленный патч.

Для установки или удаления на тестовой копии передайте её каталог явно.

```powershell
.\MusicSync.Patch.exe install 'C:\Path\To\YandexMusic-Copy'
Start-Process -FilePath 'C:\Path\To\YandexMusic-Copy\Яндекс Музыка.exe' -ArgumentList '--user-data-dir=C:\Path\To\YandexMusic-TestProfile'
# После проверки закройте тестовый экземпляр.
.\MusicSync.Patch.exe uninstall 'C:\Path\To\YandexMusic-Copy'
```

Изменённый EXE сохраняет проверку целостности Electron, а проверка Authenticode оригинального издателя для изменённого файла перестаёт проходить. После удаления патча файлы совпадают с исходными по SHA-256.
