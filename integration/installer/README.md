# MusicSync «Вместе» для Windows x64

Запустите `MusicSync-Together-0.1.10-Windows-x64.exe`. Укажите адрес сервера и нажмите «Установить патч». После запуска Яндекс Музыки в боковом меню появится «Вместе». Чтобы снять патч, нажмите «Удалить патч» в том же окне. Если Яндекс Музыка уже запущена, MusicSync закроет и снова откроет её после операции.

Поддерживаются проверенные сборки Яндекс Музыки 5.126.1 и 5.127.0. Установщик сверяет ProductVersion, package version и SHA-256 оригинальных файлов и хранит их копии в `.musicsync-together` внутри каталога приложения. При удалении он сверяет SHA-256 файлов патча и восстанавливает оригиналы соответствующей сборки. Повторный запуск того же установщика проверяет установленный патч.

При открытии совместимость проверяется в фоне без изменения файлов. Проблема выводится в существующей строке сообщения. Интерфейс сохранён: установка, удаление, адрес сервера и кнопка обновления MusicSync. Задания Планировщика и автоматической переустановки нет. Повторная установка после обновления запускается обычной кнопкой «Установить патч».

Для работы с тестовой копией передайте её каталог через `--directory`. [Сборка и проверка](../../docs/TOGETHER.md)

```powershell
.\dist\MusicSync-Together-0.1.10-Windows-x64.exe --directory 'C:\Test\YandexMusic'
```

Изменённый EXE сохраняет проверку целостности Electron, а проверка Authenticode оригинального издателя для изменённого файла перестаёт проходить. После удаления патча файлы совпадают с исходными по SHA-256.
